# Tesla Model Y Batman Paint Shop wraps

Screen wraps for the 2025+ Model Y Juniper. These are Paint Shop files, not vinyl cut files.

Personal fan art. The bat mark is an original silhouette, not DC's official logo.

## Which file

- Long Range / Premium body: `_Prem` files
- Standard / Rear-Wheel Drive body: `_Std` files
- If the nose or tail looks shifted, switch sets
- Performance has a different front bumper and needs its own template

## Install

Phone: Tesla app 4.59 or newer, Creations, Wrap, Upload. Then in the car: Toybox, Paint Shop, Wraps.

USB: format exFAT or FAT32, not NTFS. Put the PNGs in a folder named `Wraps` at the root of the drive. No map or firmware files on that drive. Plug into the glovebox port, then open the same Wraps tab.

Tesla limits: PNG, 512 to 1024 px, under 1 MB, filename max 30 characters. Up to 10 wraps from the app and 10 from USB.

## Designs

- Gotham Stealth: satin black, yellow bat on the hood, belt stripe, quarter bats
- Dark Knight: armor black, yellow belt, skyline ticks, bats on the tail
- Tactical Bat: charcoal, scratched bat, red slit accent
- Batwing Night: purple night fade, batwing on the hood

Panel maps follow Tesla's official 2025+ Model Y templates.
